1f · What each setup actually found — golden bugs vs verified real bugs the benchmark missed

One bar per cell, sorted by total real bugs found. Gray segment = golden defects found (the only thing the strict benchmark scores). Colored segment = hidden-gold defects found from the verified set (the deduplicated, individually test-validated defect set: every defect has its own test that fails on the PR head and a minimal fix that makes it pass; REPORT_FINAL §10d; GOLD_DEFECT_CATALOG.md). The longer the colored part, the more the setup finds that the benchmark never credits. The dashed line at 152 marks the "perfect" agent (as far as we know — and we are being facetious): all 42 goldens + all 110 verified defects on the six PRs. The small gray tick on each row is that cell's reachable ceiling (some cells cover fewer than the six PRs and cannot reach 152). Ranked by real bugs found, not by F1′: the F1′ leaderboard is volume-sensitive — a terse run registers zero nitpicks while a verbose one is charged for every real-but-minor item, so the best-F1′ cell sits far down this chart (fable vanilla: 19 hidden-gold defects vs glm-vis MRV high's 37).
